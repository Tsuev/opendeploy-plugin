# OpenDeploy для ИИ-агентов

Плагин помогает агенту проверить статический сайт, собрать его и опубликовать через OpenDeploy. Агент показывает найденные проблемы и состав сборки, а публикацию выполняет после вашего подтверждения.

![Путь от проекта до опубликованного сайта](docs/images/overview.svg)

## Что нужно

- Локальный агент с доступом к файлам и терминалу: Codex, Claude Code или OpenCode.
- [Node.js 22.13+](https://nodejs.org/) и npm.
- Аккаунт OpenDeploy и доступ к интернету.
- Готовый статический сайт или проект, который собирается в статические файлы с `index.html` в корне.

Серверные приложения и базы данных пока не поддерживаются. Публичный адрес также зависит от настройки сервера OpenDeploy, DNS и HTTPS.

## Установка

После публикации репозитория скачайте его:

```bash
git clone https://github.com/Tsuev/opendeploy-plugin.git
```

Далее используйте абсолютный путь к скачанной папке `opendeploy-plugin`.

### Codex / ChatGPT desktop

Добавьте локальный каталог плагинов:

```bash
codex plugin marketplace add /абсолютный/путь/к/opendeploy-plugin
```

Перезапустите приложение и установите **OpenDeploy** из источника `opendeploy-marketplace`. Для работы с файлами откройте локальный проект сайта. [Как устроены локальные каталоги Codex](https://developers.openai.com/plugins/build/plugins).

### Claude Code

Для одной сессии запустите:

```bash
claude --plugin-dir /абсолютный/путь/к/opendeploy-plugin
```

Для постоянной установки выполните в терминале:

```bash
claude plugin marketplace add /абсолютный/путь/к/opendeploy-plugin
claude plugin install opendeploy@opendeploy-marketplace
```

[Документация Claude Code по каталогам плагинов](https://code.claude.com/docs/en/plugins/create-marketplace).

### OpenCode

OpenCode подключает скилл из репозитория, без установки нативного плагина. Добавьте в `opencode.json` проекта сайта:

```json
{
  "skills": ["/абсолютный/путь/к/opendeploy-plugin/skills"]
}
```

Если файл уже есть, добавьте поле `skills`, сохранив остальные настройки. [Документация OpenCode о скиллах](https://opencode.ai/docs/skills/).

## Как опубликовать

Откройте папку сайта в агенте и напишите: **«Опубликуй мой сайт через OpenDeploy»**. При необходимости укажите путь к проекту.

![Этапы подготовки и публикации](docs/images/workflow.svg)

1. Агент проверит проект и SEO, предложит исправления. Вы решите, какие применить.
2. Агент соберёт статические файлы и покажет состав и размер сборки.
3. При первом запуске агент покажет ссылку и код для входа в OpenDeploy. Пароль и токен в чат вводить не нужно.
4. Вы выберете поддомен вида `имя.opendeploy.ru` и подтвердите публикацию.
5. Агент отправит сборку и сообщит фактический адрес и статус проверки доступности.

Для обновления сайта попросите агента опубликовать новую версию существующего проекта. Подготовка к индексации и появление сайта в поиске сообщаются только при подтверждённом статусе сервиса; сроки поисковых систем не гарантируются.

## Если возникла проблема

| Ситуация | Что проверить |
| --- | --- |
| Агент не видит сайт | Откройте папку проекта или укажите её абсолютный путь. |
| Не запускается клиент | Проверьте Node.js и выполните `npm ci --ignore-scripts` в папке `client` установленной копии плагина. |
| Не удаётся войти | Повторите `login` и подтвердите код до истечения срока. |
| Публикация не удалась | Попросите агента показать этап и ответ сервиса; проверьте настройку публичного адреса. |

## Состав репозитория

- [`skills/opendeploy/SKILL.md`](skills/opendeploy/SKILL.md) — сценарий для агента.
- [`client/bin/opendeploy.mjs`](client/bin/opendeploy.mjs) — локальный клиент авторизации и публикации.
- `plugin.json`, `.claude-plugin/` и `.agents/plugins/` — описание плагина для совместимых сред.

Клиент работает с API `https://app.opendeploy.ru`. Для локальной разработки можно задать `OPENDEPLOY_API=http://127.0.0.1:3100`. Токен хранится локально в `~/.opendeploy/`.
